# Responsive Stylesheet

This project demonstrates responsive design using CSS media queries.

## Breakpoints

- Mobile: default layout, one section per row.
- Tablet: `min-width: 772px`; sections are approximately `45vw` wide and images are no more than `30vh` high.
- Large screen: `min-width: 998px`; sections are approximately `30vw` wide.

## Files

- `index.html` - webpage structure
- `style.css` - responsive CSS media queries
